# Персональный сайт-визитка

Учебный статичный сайт-портфолио Анны Москалевой - специалиста по внедрению и автоматизации Bitrix24.

## Технологии

- HTML5 - структура страницы;
- CSS3 - внешний вид и адаптивная сетка;
- чистый JavaScript - будущая интерактивность;
- Git - история изменений.

Проект не использует backend или большие JavaScript-фреймворки.

## Как запустить локально

Для простого просмотра можно открыть `index.html` двойным щелчком. Более надёжно запустить локальный сервер из корня проекта:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Как добавить фотографию

1. Поместите оптимизированную фотографию в `images/profile/`.
2. В `index.html` найдите комментарий внутри блока `profile-placeholder`.
3. Замените placeholder на тег `<img>` с относительным путём и понятным `alt`.

Пример: `<img src="images/profile/anna.jpg" alt="Анна Москалева">`.

## Изображения и кейсы

- схемы и обезличенные скриншоты кейсов помещаются в `images/cases/`;
- сертификаты Bitrix24 помещаются в `images/certificates/`;
- сейчас в разделе «Кейсы» представлены материалы `warehouse-claim-process.png`, `automatic-email-sending.png`, `employee-messaging.png` и `scheduled-email.png`;
- личные фотографии - в `images/personal/`. Сейчас «Досуг» разделён на «Восточные танцы», «Путешествия» и «Дрессировка собак»;
- небольшие графические элементы - в `images/icons/`.

Интерактивная структура кейсов будет добавлена позже. Перед публикацией рабочих изображений обязательно удалите персональные, клиентские и корпоративные данные.

## Архив для Bitrix24

1. Проверьте, что пути к файлам относительные.
2. Проверьте сайт локально.
3. Создайте ZIP из содержимого корня проекта.
4. Не добавляйте `.git` и файлы с секретами.

В архив входят `index.html`, папки `css`, `js`, `images` и при необходимости `README.md`.

## Переключение темы

В правой части шапки находится список тем:

- **Light** - светлая тема;
- **Dark** - тёмная тема;
- **Bitrix Style** - светлая тема с акцентами в стиле Bitrix24.
- **Для слабовидящих** - высококонтрастный режим с увеличенным текстом и заметным фокусом.

Выбранный вариант сохраняется в браузере через `localStorage`, поэтому после повторного открытия страницы тема остаётся выбранной. Логика переключения находится в `js/app.js`, а цвета каждой темы - в начале `css/style.css`.
